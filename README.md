# 幻城网安 API 自动签到工具

针对 `https://api.hcnsec.cn/`（新疆幻城网安科技公益大模型 API 平台）的多账号自动签到工具。

## 功能

- 多账号批量自动签到
- 账号管理（添加 / 删除 / 列出）
- 签到状态和余额查询
- 登录失败自动重试
- 日志记录到文件
- 支持命令行批量模式（可配合 Windows 计划任务实现每日自动签到）

## 文件说明

| 文件 | 说明 |
|------|------|
| `hcnsec_auto_checkin.py` | 主程序（签到核心逻辑） |
| `web_app.py` | Web 控制台后端（Flask） |
| `static/` | Web 前端资源（HTML/CSS/JS） |
| `accounts.json` | 账号配置文件（自动生成） |
| `启动签到.bat` | 双击启动命令行交互菜单 |
| `启动网页.bat` | 双击启动 Web 控制台（推荐） |
| `批量签到_静默.bat` | 静默批量签到（适合计划任务） |
| `checkin_log.txt` | 签到日志（自动生成） |
| `requirements.txt` | Python 依赖 |

## 快速开始

### 0. Web 控制台（推荐，最直观）

双击 `启动网页.bat`，脚本会自动安装依赖并启动本地服务，随后浏览器打开
`http://127.0.0.1:5000` 即可使用可视化界面：

- 一键签到（实时进度 + 结果）
- 账号管理（添加 / 删除）
- 实时状态查询（余额 / 已用 / 连续签到 / 今日状态）
- 签到日志流（彩色高亮 + 自动滚动）

手动启动：

```bash
python web_app.py
```

### 1. 安装依赖（命令行方式）

```bash
pip install -r requirements.txt
```

### 2. 添加账号

**方式一：交互模式（推荐）**

双击 `启动签到.bat`，选择菜单 `3. 添加账号`，依次输入用户名和密码。

**方式二：命令行**

```bash
python hcnsec_auto_checkin.py --add 用户名 密码
```

### 3. 执行签到

**方式一：交互模式**

双击 `启动签到.bat`，选择 `1. 一键签到所有账号`。

**方式二：命令行批量签到**

```bash
python hcnsec_auto_checkin.py --run
```

**方式三：双击批处理**

双击 `批量签到_静默.bat`。

### 4. 查看状态

```bash
python hcnsec_auto_checkin.py --status
```

## 配置文件格式

`accounts.json` 示例：

```json
{
  "accounts": [
    {"username": "账号1", "password": "密码1"},
    {"username": "账号2", "password": "密码2"}
  ]
}
```

也可手动编辑此文件添加账号。

## 设置每日自动签到（Windows 计划任务）

1. 按 `Win + R`，输入 `taskschd.msc` 打开任务计划程序
2. 点击"创建基本任务"
3. 名称填"幻城自动签到"，触发器选"每天"，设定时间
4. 操作选"启动程序"，浏览选择 `批量签到_静默.bat`
5. 完成

## 命令行参数

| 参数 | 说明 |
|------|------|
| (无参数) | 启动交互菜单 |
| `--run` | 批量签到所有账号 |
| `--status` | 查看所有账号签到状态和余额 |
| `--add 用户名 密码` | 添加账号 |
| `--remove 用户名` | 删除账号 |
| `--list` | 列出所有已配置账号 |

## 签到原理

工具通过调用 New API 平台的 API 接口完成签到：

1. `POST /api/user/login` - 账号登录，获取会话
2. `GET /api/user/checkin` - 查询今日是否已签到
3. `POST /api/user/checkin` - 执行签到，获取额度奖励
4. `GET /api/user/self` - 查询余额
5. `POST /api/user/auth/logout` - 登出

每次签到可获得约 2000 额度（约合 ¥0.004），每日一次。

## 注意事项

- 密码以明文存储在 `accounts.json` 中，请勿泄露此文件
- 该网站未启用人机验证（Turnstile），脚本可直接调用 API
- 如果账号启用了双因素认证（2FA），无法自动签到
- 账号之间会间隔 3 秒，避免触发速率限制
- 登录失败会自动重试 2 次
